# Feature Template

## Purpose
This template is used for documenting a feature in `brain/features/`.

## How To Use
- Copy this file into `brain/features/` with a descriptive name.
- Replace placeholders with concrete product details.
- Keep the feature doc implementation-aware but product-led.

## Template
## Feature Name

## Goal
- What problem this feature solves

## Users
- Who uses it

## Flow
- Step-by-step user flow

## Data Model
- Entities involved

## API
- Required endpoints or operations

## UI Notes
- Screens and major interactions

## Edge Cases
- Failure or unusual scenarios

## Metrics
- How success is measured
