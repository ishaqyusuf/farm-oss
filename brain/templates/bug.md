# Bug Template

## Purpose
This template is used for bug records in `brain/bugs/`.

## How To Use
- Copy this file into `brain/bugs/` when a bug should be remembered long term.
- Record root cause and prevention, not just the symptom.
- Link related files or fixes where possible.

## Template
## Bug Title

## Date
- YYYY-MM-DD

## Summary
- Short description of the problem

## Root Cause
- What actually caused it

## Fix
- What changed to resolve it

## Prevention
- How to avoid it in future

## Related Files
- Relevant paths
