# Product Vision

## Purpose
This file describes the product vision, target users, and the value the product should deliver.

## How To Use
- Update when positioning or primary user segments change.
- Keep this file outcome-oriented.
- Use it to judge roadmap and feature decisions.

## Vision
Help farms run more profitably by turning daily operations into clear records, trends, and decisions.

## Primary User
- Poultry farm owners
- Poultry farm managers
- Operational staff entering daily flock records

## Core Value Proposition
- Replace notebooks with a simple digital workflow.
- Show where money is made or lost.
- Surface performance issues early.

## Product Positioning
- Prefer positioning such as `Poultry Profit Tracker` or `Farm Record & Profit Tracker`.
- Avoid broad enterprise language that raises adoption friction.

## User Experience Standard
- User opens the app.
- User adds today's record quickly.
- User sees basic insight or status.
- User leaves without friction.
