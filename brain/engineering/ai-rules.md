# AI Rules

## Purpose
This file contains repository-specific rules for AI contributors.

## How To Use
- Read before implementation.
- Update when repeated review feedback reveals a stable rule.
- Keep rules clear and operational.

## Rules
- Read relevant brain files before changing code.
- Favor the smallest useful implementation step.
- Keep product flows simple for low-friction farm operations.
- Avoid introducing livestock-specific complexity into the poultry MVP.
- Update tasks and docs as part of the same work.
- Create ADRs for major architecture or stack decisions.
