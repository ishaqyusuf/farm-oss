# Farm OSS Expo App

Expo mobile app initialized using the structural approach from the local `gnd` project.

## Commands
- `bun run dev:expo`
- `bun run --cwd apps/expo start`
- `bun run --cwd apps/expo android`
- `bun run --cwd apps/expo ios`

## Notes
- Uses Expo Router for file-based navigation.
- Starts with a simple poultry-first home screen and sample daily record screen.
- The next major step is wiring API access and shared domain models into the mobile flow.
